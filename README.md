# 🐾 Petfolio API

API desenvolvida em **C# com .NET** com o objetivo de praticar a criação e organização de uma API REST.

O projeto foi desenvolvido como um exercício de aprendizado, com foco principalmente em entender como estruturar um projeto, organizar pastas, separar responsabilidades e trabalhar com endpoints.

## 🚀 Tecnologias

* C#
* .NET
* ASP.NET Core Web API
* Swagger

## 🗂️ Organização

Durante o desenvolvimento, o projeto foi organizado buscando manter cada responsabilidade em seu devido lugar, facilitando a compreensão e manutenção do código.

A estrutura foi pensada como uma forma de aprender, na prática, como projetos de API podem ser organizados e como as diferentes partes da aplicação se relacionam.

## 🔗 Endpoints

A API possui endpoints básicos para realizar operações e testar o funcionamento da aplicação.

Os endpoints podem ser acessados e testados através do **Swagger**.

## 📚 Swagger

O **Swagger** foi utilizado para documentar e testar os endpoints da API.

Através dele é possível visualizar as rotas disponíveis, seus métodos HTTP e realizar requisições diretamente pela interface.

Projeto finalizado como parte do processo de aprendizado e prática em desenvolvimento de APIs com C#.
